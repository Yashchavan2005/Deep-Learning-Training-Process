# Deep Learning Training Process

## 📌 Project Description

This project demonstrates a simple Deep Learning training process using Python.

The project shows how a model learns by updating its weight based on prediction error. It also visualizes the training process using graphs.

## 🎯 Objective

* Understand the basic Deep Learning training process.
* Understand prediction and error calculation.
* Understand loss calculation.
* Understand weight adjustment.
* Visualize the learning process using graphs.

## 🧠 Concepts Used

* Input Data
* Weight
* Learning Rate
* Forward Pass
* Prediction
* Error
* Loss
* Weight Update
* Training Loop
* Data Visualization

## ⚙️ Working Process

```text
Input
  ↓
Weight
  ↓
Prediction
  ↓
Error Calculation
  ↓
Loss Calculation
  ↓
Weight Update
  ↓
Next Training Step
```

The model performs 20 training steps. During each step, it calculates the prediction, error, and loss, and then updates the weight.

## 📊 Visualizations

The project generates three graphs:

1. **Loss Decreasing During Training**

   * Shows how the loss changes during training.

2. **Prediction Approaching Actual Output**

   * Shows how the predicted output approaches the expected output.

3. **Weight Adjustment During Learning**

   * Shows how the weight changes during training.
